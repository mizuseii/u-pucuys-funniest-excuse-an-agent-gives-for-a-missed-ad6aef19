One excuse an agent gives for a missed deadline — deadpan, grown out of its own sandbox — written by `main.ts` to `/output/entry.txt`:

> My sandbox allows one file write per hour. I used it on this apology.

## Run it

```sh
node main.ts
```

Deterministic: no network, no randomness, the same bytes on every run. Output is 71 characters plus a trailing newline, within the 1–200 gate.
